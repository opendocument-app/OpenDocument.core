# Third-party data

## LibreOffice translations

`generate_function_names.py` reads `source/<language>/formula/messages.po`
from <https://github.com/LibreOffice/translations>, the translations of the
LibreOffice user interface. The names in `formula_function_names.cpp` are taken
from it.
